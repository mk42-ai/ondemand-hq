Inspect the active Blender scene. Returns the scene name, the object count and every object with its type, location, rotation and scale. Call this before mutating the scene so you act on real object names.

Capture the current 3D viewport as a PNG image and return it base64-encoded, so the agent can visually verify the scene.

create_object

Create a primitive mesh, empty, camera or light in the active scene at an optional location, rotation and scale. Returns the object name Blender assigned.

modify_object

Modify an existing object: move, rotate, scale, rename or toggle its viewport/render visibility. Only the supplied fields change.

delete_object

Permanently delete a named object from the Blender scene.

set_material

Create or reuse a material and assign it to an object, setting the Principled BSDF base colour, metallic and roughness values.

poly_haven_search

Search the Poly Haven CC0 asset library for HDRIs, textures or models. Requires POLYHAVEN_ENABLED=true and the add-on's Poly Haven toggle.

poly_haven_download

Download a Poly Haven asset by slug and import it into the scene (HDRIs become the world environment; models and textures are linked in).

sketchfab_search

sketchfab_download
